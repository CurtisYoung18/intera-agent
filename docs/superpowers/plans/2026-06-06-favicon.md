# Intera Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a complete favicon set (SVG, PNGs, ICO, apple-touch-icon, PWA manifest) for the Intera console app.

**Architecture:** SVG is the source of truth. A Node.js script rasterizes the SVG into all required PNG sizes and combines them into an ICO file. Layout.tsx gets `<link>` tags, and a `manifest.json` is created for PWA support.

**Tech Stack:** SVG (hand-crafted), `sharp` (SVG→PNG rasterization), `png2icojs` (PNG→ICO conversion), Next.js metadata tags

### Task 3: Create the rasterization script

- [ ] **Step 1: Write `apps/console/scripts/generate-favicons.mjs`**

```javascript
#!/usr/bin/env node
import { readFileSync, writeFileSync } from 'node:fs'
import { resolve, dirname } from 'node:path'
import { fileURLToPath } from 'node:url'
import sharp from 'sharp'
import png2ico from 'png2icojs'

const __dirname = dirname(fileURLToPath(import.meta.url))
const PUBLIC = resolve(__dirname, '../public')
const SVG_PATH = resolve(PUBLIC, 'favicon.svg')

const SIZES = [
  { size: 16,  name: 'favicon-16.png' },
  { size: 32,  name: 'favicon-32.png' },
  { size: 48,  name: 'favicon-48.png' },
  { size: 180, name: 'apple-touch-icon.png' },
  { size: 192, name: 'icon-192.png' },
  { size: 512, name: 'icon-512.png' },
]

async function main() {
  const svg = readFileSync(SVG_PATH)

  // Rasterize all PNG sizes
  for (const { size, name } of SIZES) {
    const buf = await sharp(svg).resize(size, size).png().toBuffer()
    writeFileSync(resolve(PUBLIC, name), buf)
    console.log(`  ✓ ${name} (${size}×${size})`)
  }

  // Build ICO from 16, 32, 48
  const ico16 = await sharp(svg).resize(16, 16).png().toBuffer()
  const ico32 = await sharp(svg).resize(32, 32).png().toBuffer()
  const ico48 = await sharp(svg).resize(48, 48).png().toBuffer()
  const ico = png2ico([
    { data: ico16, size: 16 },
    { data: ico32, size: 32 },
    { data: ico48, size: 48 },
  ])
  writeFileSync(resolve(PUBLIC, 'favicon.ico'), ico)
  console.log('  ✓ favicon.ico (16+32+48)')

  console.log('\nAll favicons generated.')
}

main().catch(err => { console.error(err); process.exit(1) })
```
