1. 背景与目标

Intera Agent Loop 通过 POST /api/messages（SSE 流式）提供完整的 agent 能力。接入 LiveChat 需要一个 Bridge 薄适配器，在 LiveChat Bot Agent API 与现有 Intera 接口之间翻译，使以下体验成为可能：

  • 用户在 widget 内实时看到 Intera 执行状态（Glass Bubble 动画，In-Chat App 渲染）
  • 选项交互在 widget 内完成（In-Chat App OptionList）
  • 表单收集在 widget 内完成（In-Chat App FormCard，翻转动画）
  • 人工升级无缝 transfer 给 LiveChat 真实客服
  • Agent 最终文本回复作为正常 LiveChat 消息推送
Bridge 定位：薄适配器，只调用现有 /api/messages，不接触 loop 内部实现。现有 API 的 session 管理、memory、case 状态等能力完全复用。

4. In-Chat App — 三视图设计

✅ 一期实现 · 位置：apps/chat/app/livechat-widget/

同一个 In-Chat App，三种视图，由 Bridge 推送 intera_widget_payload 事件动态切换。动态内容全部由 Intera LLM 生成，App 只负责渲染样式。

视图触发 SSE 事件渲染内容完成后动作
StatusTrack tool_executing Glass Bubble 列表，每个 skill 一条，spinner 动画 → 完成变绿勾 + 耗时 message_stop 后折叠 / 隐藏
OptionList interaction_proposed 选项行，含 label + description + 可选文字输入框 用户点选 → intera_interaction_submit → Bridge 注入 tool result
FormCard form_request 翻转卡片表单，支持 text / select / file / date 用户提交 → intera_form_submit → Bridge 注入 tool result

StatusTrack 视觉效果（Glass Bubble 风格）

动态内容注入机制：In-Chat App URL 固定（注册在 LiveChat Developer Console），LLM 生成的字段/选项通过 Bridge 推送 intera_widget_payload 自定义事件实时注入，App 监听并渲染。无需修改 App URL 或重新注册。

注册方式

  1. 在 developers.livechat.com 创建私有 App（不上 Marketplace）
  2. Placement: Chat Widget
  3. App URL: https://chat.intera.io/livechat-widget
  4. 安装到 LiveChat Organization → 完成

事件格式规范

// Bridge → In-Chat App（触发视图切换 + 注入内容）
send_event({ type: "intera_widget_payload", properties: {
  kind: "status_track" | "propose_interaction" | "request_user_input",
  caseId: "case_xxx",
  // status_track:
  step: { id: "kb_hybrid_retrieve", label: "知识库检索", state: "running"|"done", durationMs: 800 },
  // propose_interaction:
  options: [{ id: "refund", label: "申请退款", description: "3-5个工作日", inputType: "none"|"text" }],
  // request_user_input:
  fields: [{ id: "order_id", type: "text", label: "订单号", required: true }]
}})

// In-Chat App → Bridge（用户完成交互）
window.LiveChatWidget.call("send_event", { type: "intera_interaction_submit", properties: { caseId, optionId, input? } })
window.LiveChatWidget.call("send_event", { type: "intera_form_submit",        properties: { caseId, answers: { field_id: value } } })

5. 文本输出策略

✅ 已确定：Buffer → 一次性推送

LiveChat Bot Agent API 不支持流式更新消息，Bridge 缓冲所有 text_delta，在 message_stop 时一次性 send_event。

用户感知：StatusTrack 动画实时更新，最终文本回复整段出现，无中间卡顿。

若未来 LiveChat 支持消息原地更新，可改为边收 text_delta 边更新，实现流式打字效果，Bridge 侧仅改发送策略，其余不变。

核心逻辑（伪代码）

// lib/livechat/bridge.ts — SSE 消费核心
for await (const event of parseSSE(stream)) {
  switch (event.type) {
    case 'tool_executing':
      if (session.showSkillStatus)   // 读 AgentConfig.livechatShowSkillStatus
        await sendWidgetPayload(chatId, { kind: 'status_track', step: { id: event.data.toolName, state: 'running' } })
      break
    case 'skill_result':
      await sendWidgetPayload(chatId, { kind: 'status_track', step: { id: event.data.toolName, state: 'done', durationMs: event.data.durationMs } })
      break
    case 'interaction_proposed':
      await sendWidgetPayload(chatId, { kind: 'propose_interaction', ...event.data })
      break
    case 'form_request':
      await sendWidgetPayload(chatId, { kind: 'request_user_input', ...event.data })
      break
    case 'text_delta':
      session.textBuffer += event.data.text
      break
    case 'message_stop':
      if (session.textBuffer) await sendMessage(chatId, session.textBuffer)
      session.textBuffer = ''
      break
    case 'escalated':
      await transferChat(chatId, { caseId: session.caseId })
      break
  }
}

7. Console 集成配置页

✅ 已确定：Console 侧边栏新增 "集成" 标签页

在 Console Agent 侧边栏（现有 Settings / Memory 等标签旁）新增 集成 标签页，per-customer 配置 LiveChat 集成参数：

配置项类型说明
LiveChat Bot Access Tokenpassword inputBridge 调用 LiveChat Bot Agent API 的凭证，加密存 DB
LiveChat License IDtext input你的 LiveChat license 号
显示 Skill 执行状态toggle开：StatusTrack 对客户可见；关：静默执行，只显示最终回复
集成状态readonly badge显示 webhook 是否已注册、Bot 是否在线

数据存在 LiveChatConfig 表，Bridge 启动时读取，30s TTL 缓存（与 AgentConfig 缓存策略一致）。

8. DB Schema 变更

✅ 已确定：新增两张表，prisma db push 即可
// packages/shared/prisma/schema.prisma 新增

model LiveChatSession {
  chatId      String   @id                    // LiveChat chat_id
  customerId  String
  userId      String
  caseId      String                         // 当前活跃 case，用于 formResult / interactionResult
  state       String   @default("idle")         // idle | thinking | waiting_choice | waiting_form | transferred
  textBuffer  String   @default("")            // 累积 text_delta
  updatedAt   DateTime @updatedAt
}

model LiveChatConfig {
  id               String   @id @default(cuid())
  customerId       String   @unique
  botAccessToken   String                         // 加密存储
  licenseId        String
  showSkillStatus  Boolean  @default(true)         // 客户是否可见 StatusTrack
  enabled          Boolean  @default(false)        // 整体集成开关
  createdAt        DateTime @default(now())
  updatedAt        DateTime @updatedAt
}
