## 添加知识块（文本类）

为文本类文档添加知识块。系统将依次执行分块/切片、嵌入/向量化，最后将为文档添加新的知识块。

注：嵌入模型使用的是默认的模型，不可在 API 内定义。

## 请求方式

`POST`

## 调用地址

`https://api-${endpoint}.gptbots.ai/v1/bot/doc/chunks/add`

## 调用验证

详情参见 [API 概述](https://www.gptbots.ai/src/zh_CN/API%20%E6%96%87%E6%A1%A3/%E6%A6%82%E8%BF%B0.md)的鉴权方式说明。

## 请求

### 请求示例

### 请求头

| 字段          | 类型              | 描述                                                         |
| ------------- | ----------------- | ------------------------------------------------------------ |
| Authorization | Bearer ${API Key} | 使用 Authorization: Bearer ${API Key}进行调用验证，请在 API 密钥页面获取密钥作为 API Key。 |
| Content-Type  | application/json  | 数据类型，取值为 `application/json` 。                       |

### 请求参数

| 字段     | 类型          | 必填 | 说明                             |
| -------- | ------------- | ---- | -------------------------------- |
| doc\_id  | String        | 是   | 要添加知识块的文档的 ID。        |
| chunks   | Array<Object> | 是   | 知识块内容。                     |
| content  | String        | 是   | 知识块的内容，最长 1000 Tokens。 |
| keywords | Array<String> | 否   | 知识块的关键词。                 |
