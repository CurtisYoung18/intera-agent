# AI Programming Log — TEMPLATE

> Copy this template to create your personal log: `[your-name].md`
> Commit your log with every PR. The team lead reviews logs during standup.

---

## Log Entry Format

```markdown
## [YYYY-MM-DD]

### [HH:MM] — [Brief Task Description]
- **AI Tool:** [Claude Code / Copilot / Cursor / Other]
- **Model:** [e.g., claude-sonnet-4-20250514] (optional)
- **Files Changed:**
  - `path/to/file.ts` — [what changed]
  - `path/to/other.tsx` — [what changed]
- **Summary:** [2-3 sentences describing what the AI did and why]
- **Manual Edits:** [any changes you made by hand after the AI output]
- **Issues:** [any problems, wrong decisions, or surprises]
- **Time Saved:** [rough estimate vs. writing manually]
```

## Rules

1. **Log every AI-assisted change.** No exceptions. One entry per meaningful task.
2. **Be specific about files.** Don't write "updated several files" — list them.
3. **Note failures.** If the AI got something wrong, record it. This helps the team learn which tasks AI is weak at.
4. **Commit the log.** Your log is part of the repo. Review it before merging.
5. **One file per person.** Don't create multiple log files for yourself.
